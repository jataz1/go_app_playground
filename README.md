# go_app_playground

A playground repository for Go applications and experiments.

## Getting Started

### Prerequisites

- [Go](https://go.dev/doc/install) (version 1.22+ recommended)
- [Git](https://git-scm.com/)

### Development

```bash
# Initialize a Go module (replace with your module path)
# go mod init github.com/<username>/go_app_playground

# Run tests
# go test ./...
```
